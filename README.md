# English Peg Solitaire – Monte Carlo Simulator

Given the rules of English Peg Solitaire, this program simulates a player
making uniformly random valid moves and estimates the following statistics:

  a) Probability of winning (reaching the single-center-peg configuration)
  
  b) Probability of ending with exactly k pegs remaining, for k in {1, ..., 32}
  
  c) Probability that the game lasts exactly N moves, for N in {1, ..., 31}
  
  d) Expected game duration (average number of moves)
  
  e) Expected number of pegs in the terminal configuration
